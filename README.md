# E-Commerce Local Web Application

A lightweight full-stack e-commerce web application built with **Node.js**, **Express**, and **Vanilla JavaScript**, designed to run smoothly locally without requiring heavy external database installations.

## 🚀 Features
* View a dynamic list of available products.
* Add products to a local shopping cart.
* In-memory data management for fast testing and development.
* Clean and responsive user interface.

## 🛠️ Tech Stack
* **Backend:** Node.js, Express.js, CORS
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
* **Storage:** In-Memory Array / LocalStorage

## ⚙️ Installation & Setup

Follow these steps to run the project locally on your machine:

1. **Clone the repository:**
   ```bash

2.Navigate to the project directory:
cd ecommerce-local-app
